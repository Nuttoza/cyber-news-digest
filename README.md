# ระบบรวบรวมและสรุปข่าวไซเบอร์ซีเคียวริตี้ประจำวัน (Cyber Threat Intelligence Daily Digest)

ระบบรวบรวมข่าวภัยคุกคามทางไซเบอร์จากสำนักข่าวชั้นนำระดับโลกในรอบ 24 ชั่วโมง คัดเลือก 5 ข่าวที่มีนัยสำคัญระดับสูง แปลและสรุปเป็นภาษาไทย 1-2 บรรทัด สกัดตัวชี้วัดภัยคุกคาม (IOC) วิเคราะห์ผลกระทบต่อหน่วยงานความมั่นคงของไทย และเสนอแนวทางปฏิบัติสำหรับทีม SOC พร้อมส่งออกเป็นเอกสาร Word (.docx) และ PDF (.pdf) อัตโนมัติ

---

## จุดเด่นของระบบ

1. **ครอบคลุมข่าวกรองระดับโลก:** ดึงข่าวจาก The Hacker News, BleepingComputer, SecurityWeek, The Record, Dark Reading, ESET WeLiveSecurity ฯลฯ
2. **กรองช่วงเวลาแม่นยำ:** ดึงเฉพาะข่าวสดใหม่ในรอบ 24 ชั่วโมง และตัดข่าวที่ซ้ำประเด็นเดียวกันออก
3. **จัดอันดับความรุนแรง (Threat Scoring):** ให้น้ำหนักกับ Zero-day, Ransomware, Critical CVE, RCE, และ Supply Chain โจมตี
4. **สรุปภาษาไทยกระชับ 1-2 บรรทัด:** คงศัพท์เทคนิคที่จำเป็น ชี้ชัดว่าใครทำอะไร และต้องรับมืออย่างไร
5. **สกัด IOC อัตโนมัติ:** คัดแยก CVE, SHA256/MD5 Hashes, C2 IPs (พร้อม Defang เช่น `192.168.1[.]1`)
6. **วิเคราะห์ผลกระทบต่อความมั่นคงไทย:** ประเมินความเสี่ยงต่อหน่วยงานความมั่นคง ภาครัฐ และโครงสร้างพื้นฐานสำคัญทางสารสนเทศ (CII)
7. **แนวทางปฏิบัติสำหรับทีม SOC:** ระบุสิ่งที่ต้องตรวจสอบและมาตรการรับมือเชิงเทคนิค (เช่น การเพิ่ม Blocklist, Threat Hunting, ตรวจสอบเวอร์ชัน)
8. **สร้างไฟล์ Word (.docx) และ PDF (.pdf):** จัดรูปแบบเป็นทางการ ใช้ฟอนต์ TH Sarabun New
9. **รันอัตโนมัติบน Cloud ฟรี 100%:** ทำงานทุกวันเวลา 02:00 น. (เวลาไทย) ผ่าน GitHub Actions โดยไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้

## วิธีการสั่งให้ระบบทำงานแบบ Manual (สั่งรันด้วยตนเอง)

หากต้องการดึงข่าวและสร้างไฟล์เอกสารทันทีโดยไม่ต้องรอรอบเวลาอัตโนมัติ:

1. ไปที่แท็บ **Actions** บน GitHub: [https://github.com/Nuttoza/cyber-news-digest/actions](https://github.com/Nuttoza/cyber-news-digest/actions)
2. ที่แถบเมนูด้านซ้าย คลิกเลือกเวิร์กโฟลว์ **Daily Cyber Threat News Digest**
3. ทางด้านขวามือจะมีปุ่ม **Run workflow**
4. คลิกที่ปุ่ม **Run workflow** แล้วกดปุ่มสีเขียว **Run workflow** เพื่อยืนยัน
5. ระบบจะเริ่มประมวลผลบนคลาวด์ทันที และสร้างไฟล์เอกสารให้พร้อมดาวน์โหลดภายในประมาณ 1–2 นาที

---

## วิธีการดาวน์โหลดไฟล์ PDF และ Word ที่ระบบสร้างขึ้น

เอกสารสรุปฉบับเต็ม (.pdf และ .docx) จะถูกจัดเก็บไว้ในแต่ละรอบการทำงานของ GitHub Actions:

1. ไปที่แท็บ **Actions** บน GitHub: [https://github.com/Nuttoza/cyber-news-digest/actions](https://github.com/Nuttoza/cyber-news-digest/actions)
2. คลิกเลือกรายการทำงานของวันที่ต้องการ (รายการที่มีเครื่องหมายถูกสีเขียว)
3. เลื่อนลงไปด้านล่างสุดของหน้า จะพบหัวข้อ **Artifacts**
4. คลิกที่ชื่อไฟล์ เช่น `cyber-threat-digest-XX`
5. เบราว์เซอร์จะดาวน์โหลดไฟล์ Zip ซึ่งภายในจะบรรจุทั้งเอกสาร **PDF (.pdf)** และ **Word (.docx)** ของรอบนั้นๆ ให้เปิดใช้งานได้ทันที
